# You're set

The window is yours: the rail, the project picker, the command field, the actions, the bell, the
workspace and the status bar.

A few things worth knowing — the buttons are drawn below as they appear in the title bar:

- **Click for instant help**, beside **Help**: click it, then point at any control and a balloon
  says what it is and what it does. Click it again, or press **Esc**, to leave. **⇧F1** does the
  same from the keyboard.
- **Help** opens the documentation for wherever you are standing; **F1** does the same.
- **More**, the chevron beside **Settings**, holds **Show onboarding**, which brings these pages
  back, the tour with them.

Open a project and enter the **IDE** mode, and a short walk through the project's modes follows.
